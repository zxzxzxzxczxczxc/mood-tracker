# Трекер настроения при повседневной активности

## Описание проекта

Проект представляет собой веб-приложение для отслеживания эмоционального состояния пользователя во время выполнения повседневных дел.

Пользователь может:
- выбирать вид активности;
- оценивать своё настроение;
- оставлять заметки;
- просматривать историю записей;
- анализировать статистику;
- просматривать наиболее позитивные и негативные занятия.

Основная задача проекта — помочь пользователю лучше понимать своё эмоциональное состояние и выявлять занятия, которые положительно или отрицательно влияют на настроение.

---

# Актуальность темы

В условиях современного ритма жизни люди всё чаще сталкиваются со стрессом, эмоциональным выгоранием и снижением продуктивности. При этом многие не анализируют своё эмоциональное состояние из-за нехватки времени или сложности подобных процессов.

Данное веб-приложение позволяет быстро и удобно фиксировать своё состояние, автоматически собирать статистику и визуализировать результаты. Это помогает пользователю повысить уровень осознанности, улучшить планирование задач и эффективнее распределять нагрузку.

---

# Целевая аудитория

Основной целевой аудиторией являются:
- студенты;
- люди с высокой учебной или рабочей нагрузкой;
- пользователи, интересующиеся саморазвитием;
- люди, стремящиеся к более эффективному управлению своим эмоциональным состоянием.

---

# Функции и возможности

- Регистрация и авторизация пользователей
- Выбор типа активности
- Оценка настроения
- Добавление заметок
- Сохранение истории записей
- Фильтрация и сортировка истории
- Просмотр статистики:
  - за день;
  - за месяц;
  - за всё время
- Определение наиболее позитивных занятий
- Определение наиболее негативных занятий
- Визуальное отображение статистики
